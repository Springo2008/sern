The SERN Interceptor

The SERN Interceptor is a 3D-printed, high-speed FPV platform built for speed, repairability, and home fabrication. The frame is optimized for 5-inch propellers, an aerodynamic fuselage, and centralized mass.

The goal of this project is to design and build a high-speed drone that others can make at home. I have designed it so it can be 3D-printed at home without extra carbon fiber parts. Total cost for everything is around 4–5000 NOK.

The project is open source. 3D files, a parts list, and a build guide will be released as the design is fully tested. The aim is for others to be able to build the drone themselves using readily available parts.
